# /new-post — быстрый черновик

> **Для полного цикла со шлюзами используйте `/create-article "<тема>"`** —
> он проходит все шлюзы качества автоматически (factcheck, редполитика,
> SEO, каннибализация).

`/new-post` подходит для быстрого исследования темы или создания черновика
без обязательной публикации. Аргументы:
- `"<тема>"` — обязательно, формулировка темы или рабочий заголовок;
- `[целевой запрос]` — опционально, основной поисковый ключ.

## Этапы

1. **Research** (агент `research-specialist`).
   - Собрать НПА, сроки, штрафы, исключения.
   - Сформировать research brief по шаблону агента.
   - Сохранить как `.claude/research/YYYY-MM-DD-slug-brief.md` (gitignore).

2. **Каннибализация** — до написания статьи.
   - Проверить `src/data/editorial-plan.json` и `content-plan-2026.md` на
     статью с тем же целевым запросом. Плагин claude-blog (`/blog
     cannibalization`) даёт то же точнее, если установлен локально — в
     облачном контейнере он не сохраняется между сессиями, см. `docs/tools.md`.
   - Если пересечение > 50% — остановиться и предложить обновить
     существующий материал вместо создания нового.
   - Зафиксировать результат в research brief.

3. **Content** (агент `content-writer`).
   - На основе brief написать статью 1500–2500 слов на русском.
   - Структура: лид → 5–7 H2 → таблица/чек-лист → FAQ → заключение.
   - 3+ внутренних ссылок, ссылки на НПА.
   - Сохранить как `src/content/blog/YYYY-MM-DD-slug.md` с `draft: true`.

4. **SEO** (агент `seo-optimizer`).
   - Прогнать чек-лист (title, description, H1/H2, перелинковка, slug).
   - Предложить дополнительную разметку (FAQPage, HowTo) — если применимо.
   - Подсветить P0/P1/P2 правки.

5. **AI-детекция** (`/check-ai <файл>` + `node scripts/check-ai-markers.mjs <файл>`).
   - Прогнать оба инструмента на написанной статье.
   - Скор должен быть ≤ 5. Если выше — исправить стоп-фразы и структуру.
   - Машинный скрипт выдаёт конкретные строки с заменами.

6. **Фактчекинг** — блокирующий gate. `/factcheck <slug>` (свой стек, не
   плагин claude-blog).
   - Скрипт `scripts/factcheck/extract-claims.mjs` извлекает даты, штрафы,
     ст. КоАП, ссылки на НПА.
   - Скилл сверяет каждый claim с первоисточником через WebSearch/WebFetch.
   - Решения принимаются по `docs/editorial-policy.md` (класс A — правим,
     класс B — добавляем disclaimer, класс C — пропускаем).
   - Результат: `src/data/factcheck/results/<slug>.json` + автомаркер
     `.claude/factchecked/<slug>` с датой.
   - При критических расхождениях статья остаётся в `draft: true`.
   - Подробнее — `docs/factcheck.md`.

7. **AI-цитируемость** (опционально, `/blog geo <файл>` — плагин
   claude-blog, если установлен локально).
   - Оценить passage-level citability под ChatGPT / Perplexity / AI Overviews.
   - Сгенерировать citation capsules (40–60 слов) для каждого H2.
   - Вставить TL;DR-блок, если отсутствует.

8. **Рерайт под соцканалы** (агент `social-media-manager`, по запросу).
   - На основе готовой статьи подготовить адаптации: Telegram, VK, Дзен,
     email-дайджест.
   - Сохранить как `.claude/social/YYYY-MM-DD-slug.md` (gitignore) —
     четыре раздела, по одному на канал.
   - Модуль не публикует и не знает, где выйдет исходник — ссылки на
     публикацию оставляет плейсхолдером для принимающего проекта.

9. **Финализация** (вручную).
   - Перепроверить факты по первоисточникам.
   - Снять `draft: true` → `draft: false`.
   - Убедиться, что маркер `.claude/factchecked/<slug>` создан.

## Категории

Каждая статья помечается одной категорией (поле `categories` во frontmatter):
- `ts-piot` — ТС ПИоТ
- `kkt` — онлайн-кассы, ФН, ОФД, модели касс
- `markirovka` — маркировка Честный знак
- `egais` — ЕГАИС и учёт алкоголя
- `zakonodatelstvo` — налоги, ЭДО, трудовое право, маркетплейсы

## Naming convention

- Файл: `YYYY-MM-DD-kebab-slug.md`.
- Slug: транслит ключевого запроса, ≤ 60 символов, без дат.

## Quality gates

- 1500+ слов.
- Все цифры со ссылкой на НПА.
- 3+ внутренних ссылок.
- Frontmatter полный.
- Никаких артефактов английского текста или эмодзи.
- `/check-ai` + `check-ai-markers.mjs` — скор ≤ 5.
- Каннибализация — нет дублей с > 50% пересечением ключей в контент-плане.
- `/factcheck` — нет критических расхождений; маркер `.claude/factchecked/<slug>` создан.
- `/blog geo` — AI Citation score ≥ 60 (если плагин claude-blog установлен).
