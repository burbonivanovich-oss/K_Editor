# /cycle-backlog — рутина A0: недельный бэклог тем

Идёт **перед** рутиной A (`/cycle-plan`). A0 отвечает на вопрос «о чём
вообще писать», A — «что из согласованного берём в этот цикл».

Раз в неделю. Редактор открывает таблицу, проставляет решения и закрывает
её — искать темы самому не нужно.

**Тема, по которой редактор сказал «нет», не возвращается.** До этого
отклонённая тема всплывала в следующем же прогоне: Wordstat не помнит
решений редактора.

---

## Шаг 1 — Собрать кандидатов

```bash
node scripts/topics/generate-backlog.mjs --limit 15
```

Скрипт берёт последний `discoveries/**/diffs/<дата>.json`, отбрасывает
уже покрытое (`editorial-plan.json` + `seo.keywords` опубликованных
статей), снимает заглушённые темы и сортирует по величине движения.
Прорыв снизу весит в 1.5 раза больше ровного роста: это тема, которой
неделю назад фактически не было.

По каждой теме проставляется «зачем сейчас» — рост частотности,
приближающийся гос-триггер, объём запросов. Без обоснования редактор
решает вслепую.

### Сигналы из мониторингов

`/monitor-rss` и `/monitor-competitors` работают в сессии и файлов на
диске не оставляют — забрать их автоматически неоткуда. Если в этом
прогоне они запускались, сложить находки в JSON и передать явно:

```bash
node scripts/topics/generate-backlog.mjs --signals /tmp/signals.json
```

```json
[{ "topic": "...", "cluster": "kadry", "source": "monitor-rss",
   "note": "ФНС опубликовала форму, вступает с 01.10.2026" }]
```

## Шаг 2 — Выложить редактору

Отдельная таблица, не та, где живёт контент-план: у бэклога недельный
ритм, у плана — месячный, мешать их в одном листе неудобно обоим. Лежит в
корневой папке редакции рядом с контент-планом — папку цикла бэклог не
заводит, в нём ещё нет статей.

```bash
node scripts/drive-sync.mjs init-backlog \
  --week $(date -u +%F) --items /tmp/backlog.json
```

Скрипт вернёт `sheetId` и `sheetUrl` — их и передать редактору. Повторный
запуск с тем же `--week` переиспользует таблицу, а не плодит дубли.

Колонки: тема, кластер, зачем сейчас, источник — заполняет бот;
**Решение**, **Кто пишет**, **Причина отказа** — заполняет редактор.

| Колонка | Значения |
|---|---|
| Решение | `согласовано` / `не согласовано` |
| Кто пишет | `AI` / `пишем сами` / `пока неактуально` |
| Причина отказа | обязательна при «не согласовано» |

`пока неактуально` — не отказ и не запуск: тема остаётся в бэклоге и в
следующий раз приходит без повторного обоснования.

## Шаг 3 — Разобрать решения

Следующим проходом (или вручную после закрытия таблицы):

```bash
node scripts/drive-sync.mjs pull-backlog --sheet-id <id> > /tmp/backlog-decisions.json
```

Отдаёт строки с полями `topic`, `cluster`, `decision`, `who`, `reason`.
Дальше — по правилам ниже.

**Согласовано** → тема уходит в контент-план, откуда её заберёт
`/cycle-plan`. `Кто пишет: AI` — в очередь `/create-article`;
`пишем сами` — помечается и в очередь не идёт.

**Не согласовано** → причина обязательна, и от неё зависит поведение:

- **«категорически не наше ядро»** — записать с `--reason core`:

  ```bash
  node scripts/topics/suppressions.mjs add "<тема>" --reason core \
    --cluster <кластер> --note "<слова редактора>"
  ```

  Глушится на 90 дней вместе с похожими формулировками — порог
  согласован с окном `/monitor-competitors`. Сравнение идёт по основам
  слов, поэтому смена падежа отказ не обходит.

- **«не тот угол»** — записать с `--reason angle` (30 дней, глушится
  только эта формулировка) и **сразу в этом же прогоне** предложить
  замену: другой ракурс той же темы или related-фразу из тех же
  Wordstat-данных. Замена идёт следующей строкой в таблице.

Проверить перед добавлением темы:

```bash
node scripts/topics/suppressions.mjs check "<тема>"   # код 1 = заглушена
node scripts/topics/suppressions.mjs list
```

## Шаг 4 — Тема от редактора

Редактор может добавить тему сам, но **дописанной строки недостаточно**:
её не отличить от черновика или недозаполненной правки. Нужен явный
сигнал — отметка в колонке «Запустить ресёрч».

Только после неё запускается `/research-topic <тема>`. Строка без
отметки не трогается: возможно, редактор ещё думает.

Это отличается от рутины A, где «дописать строку внизу» достаточно, —
и отличается намеренно.

---

## Правила

- **Не решать за редактора.** Бот не ставит «согласовано» и не
  придумывает причину отказа.
- **Не приносить заглушённое.** Если тема попала в бэклог вопреки
  заглушке — это баг сопоставления, а не повод её протащить.
- **Отказ без причины — не отказ.** Строка «не согласовано» с пустой
  причиной остаётся необработанной, и об этом надо сказать в отчёте:
  иначе тема тихо вернётся через неделю.
- Язык таблицы и отчёта — только русский.
