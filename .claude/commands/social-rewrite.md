# /social-rewrite — адаптация под площадки

Раньше рерайт запускался, только если кто-то вспоминал попросить: ни
команды, ни привязки к событию, ни чек-листа. Теперь вызов явный, а
состояние сохраняется.

Вызов: `/social-rewrite 2026-05-01-ts-piot-shtrafy`

Без `--platform` делаются все недостающие площадки. С `--platform` —
только указанная.

---

## Шаг 1 — Что уже сделано

```bash
node scripts/social-state.mjs get <slug>
```

Повторять готовое не нужно: адаптация переписывает текст, а не улучшает
его с каждым проходом. Если всё сделано — сказать об этом и выйти.

Промостраница (`promo`) в «все недостающие» **не входит**: она нужна не
каждой статье, а той, под которую есть оффер. Запускается только явным
`--platform promo`.

## Шаг 2 — Проверить, что адаптировать есть что

Статья должна существовать и быть вычитанной: `src/content/blog/<slug>.md`.

Адаптировать черновик (`draft: true`), не прошедший приёмку, — значит
переписывать текст, который ещё изменится. Если статья в `draft: true`,
предупредить и спросить подтверждение.

## Шаг 3 — Рерайт

Передать статью агенту `social-media-manager` со списком недостающих
площадок. Форматы, скелеты и правила — в его инструкции.

Результат — `src/data/social/<slug>.md`, разделами по площадкам.
**Не `.claude/social/`**: та папка в `.gitignore`, результат оттуда
пропадает при следующей сессии.

## Шаг 4 — Отдать редактору

Редактор работает только в Google Drive. Адаптация, лежащая в git,
для него не существует — принять или поправить её тем же путём, что
статью, он не сможет.

```bash
node scripts/drive-sync.mjs make-doc \
  --md src/data/social/<slug>.md \
  --title "Соцканалы — <заголовок статьи>" \
  --folder <folderId текущего цикла>
```

`folderId` — из `node scripts/cycle-state.mjs get --json`, поле
`drive.folderId`. Цикла нет — выложить в корневую папку и сказать об этом.

## Шаг 5 — Записать состояние

По каждой готовой площадке:

```bash
node scripts/social-state.mjs mark <slug> --platform <p> --doc-id <docId>
```

## Шаг 6 — Закоммитить

```bash
git add src/data/social/<slug>.md src/data/social-adaptations.json
git commit -m "social: <заголовок статьи> (<площадки>)"
```

## Когда запускать

- **После приёмки статьи редактором.** `/cycle-listen` на шаге «редактор
  принял» проверяет `social-state.mjs get <slug>` и, если не сделано
  ничего, добавляет строку в свой отчёт — не запускает сам, а напоминает.
  Решение о рерайте остаётся за человеком: не каждой статье он нужен.
- **По запросу** — когда понадобилась конкретная площадка.

Что не сделано по всем статьям сразу:

```bash
node scripts/social-state.mjs list --pending
```

## Правила

- **Не выдумывать фактуру.** В адаптации не появляется ничего, чего нет
  в исходной статье: ни цифр, ни норм, ни обещаний.
- **Не публиковать.** Модуль не знает, где выйдет текст, и не постит его.
- **Не переделывать готовое** без явной просьбы — см. шаг 1.
- Язык — только русский.
