# Кнопка редактора в Google-таблице

Редактор не заходит в GitHub — это устройство модуля, а не недосмотр. До
сих пор из этого следовала четырёхчасовая задержка: правку он оставлял в
таблице и ждал, пока рутина B придёт по расписанию.

Кнопка убирает ожидание. Редактор жмёт пункт меню в таблице, которая у
него и так открыта, — запрос уходит в GitHub сразу.

## Как это устроено

```
Google-таблица              GitHub                       Рутина B
─────────────────           ─────────────────            ──────────────
меню «Контур»       ──►     editor-request.yml    ──►    /cycle-listen
                            кладёт запрос в               читает очередь
токен в свойствах           src/data/editor-              первой, до
скрипта, не в                requests/ и коммитит         обхода таблицы
браузере
```

Токен живёт в свойствах скрипта на стороне Google. Редактор его не видит,
не вводит и не может потерять: настраивает один раз владелец. В таблицу
токен не пишется, в репозиторий не попадает.

## Статус установки

Скрипт **установлен** в таблицу «Редакция — темы и план» 11.08.2026:
проект Apps Script «Контур — меню редактора», меню в панели появляется.
Осталось одно — токен: без него пункты меню откроют окно «Токена нет.
Меню Контур → „Настроить доступ"».

## Что нужно один раз настроить

### 1. Выпустить токен

GitHub → Settings → Developer settings → **Fine-grained tokens** →
Generate new token.

| Поле | Значение |
|---|---|
| Repository access | Only select repositories → `K_Editor` |
| Permissions → Actions | **Read and write** |
| Expiration | на ваше усмотрение; после истечения кнопки замолчат |

Больше ничего давать не нужно. `Actions: write` позволяет запускать
workflow и не даёт ни читать код, ни писать в репозиторий напрямую.

### 2. Вставить скрипт в таблицу

1. Открыть таблицу плана → **Расширения → Apps Script**.
2. Удалить содержимое `Код.gs`, вставить
   `integrations/google-apps-script/kontur-menu.gs` из репозитория.
3. Сохранить, перезагрузить вкладку с таблицей.
4. В таблице появится меню **Контур**.

### 3. Сохранить токен

Меню **Контур → «Настроить доступ»** → вставить токен.

Затем **Контур → «Проверить связь»**. Диалог должен показать имя workflow
и состояние `active`. Это подтверждает доступ на чтение; право на запуск
проверится первой реальной отправкой — отдельного способа GitHub не даёт.

При первом запуске Google спросит разрешения скрипта (доступ к таблице и
внешним запросам) — их даёт тот, кто настраивает.

## Что видит редактор

| Пункт меню | Когда жать |
|---|---|
| Срочная правка — позвать сейчас | Правка нужна раньше планового прохода |
| Вопрос по теме | Нужен ответ, а не правка |
| Док поправлен — перечитать | Внёс изменения, можно смотреть заново |

Тема берётся из строки, на которой стоит курсор, — объяснять словами, о
какой статье речь, не нужно. Если курсор не на строке с темой, кнопка
скажет об этом и ничего не отправит.

## Ограничение, о котором надо знать

Запрос **попадает в очередь сразу**, но саму рутину B кнопка не запускает.
Рутины — это триггеры Claude, а не GitHub Actions; из Apps Script их не
дёрнуть.

Практически это значит: очередь разбирается на ближайшем проходе рутины B,
и срочное больше не стоит в общей очереди за неспешным. Но если рутина B
ходит раз в 4 часа, ожидание до 4 часов остаётся.

Чтобы убрать и его, нужен запуск Claude по требованию — это отдельное
решение с отдельной ценой (Claude Code Action в workflow плюс ключ API,
оплата за каждый прогон). Пока оно не принято, кнопка даёт приоритет и
отметку времени, но не мгновенный ответ.

## Если кнопка молчит

| Что говорит | Что делать |
|---|---|
| «Токен не принят (401)» | Токен истёк или отозван — выпустить новый |
| «Доступ запрещён (403)» | У токена нет `Actions: write`, либо Actions отключены в настройках репозитория |
| «Не найдено (404)» | Нет доступа к репозиторию, либо `editor-request.yml` отсутствует в ветке `main`: `workflow_dispatch` видит только файлы ветки по умолчанию |
| «GitHub не принял поля (422)» | Список полей в workflow разошёлся со скриптом таблицы — сверить `inputs` в `editor-request.yml` и `dispatch_()` в `kontur-menu.gs` |
| Меню «Контур» не появилось | Не перезагружена вкладка с таблицей после сохранения скрипта |

## Если меняется раскладка таблицы

Скрипт читает тему из колонки B и статус из колонки I — это повторяет
`COLS` в `scripts/drive-sync.mjs`. Меняете колонки там — поправьте
константы `COL_TOPIC` и `COL_STATUS` в начале `kontur-menu.gs`, иначе
кнопка возьмёт не ту колонку и передаст мусор.
