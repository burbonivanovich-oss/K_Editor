# Меню редактора в Google-таблице

Меню «Контур» работает внутри Google Sheets и не требует GitHub или
внешнего токена. Команды «Срочная правка», «Вопрос по теме» и
«Док поправлен» записывают помеченный запрос в колонку «Комментарий»
выбранной строки. Локальная рутина B читает его в ближайший проход.

## Как это устроено

```text
Google-таблица                         Локальная задача B
──────────────────────────────────    ───────────────────────────
меню «Контур»                         читает колонку «Комментарий»
        │                                         ▲
        └── пишет [Срочно] / [Вопрос] / ──────────┘
            [Док поправлен — перечитать]
```

Редактор остаётся в Google Drive. Источником запроса служит сама
таблица, которую B и так опрашивает по расписанию. Отдельной очереди в
репозитории и сетевого диспетчера нет.

## Установка

1. Откройте таблицу плана → **Расширения → Apps Script**.
2. Замените содержимое `Код.gs` файлом
   `integrations/google-apps-script/kontur-menu.gs`.
3. Сохраните проект и перезагрузите таблицу.
4. Убедитесь, что появилось меню **Контур**.

После миграции удалите старое свойство скрипта `GITHUB_TOKEN`, если оно
сохранилось. Новый скрипт его не читает.

## Что видит редактор

| Пункт меню | Что появится в «Комментарий» |
|---|---|
| Срочная правка | `[Срочно] <текст>` |
| Вопрос по теме | `[Вопрос] <текст>` |
| Док поправлен — перечитать | `[Док поправлен — перечитать] <текст>` |

Если в ячейке уже есть текст, новый запрос дописывается с новой строки.
Кнопка берёт тему из текущей строки; курсор выше первой строки данных или
пустая тема приводят к понятному сообщению без записи.

## Письма редакции

Меню умеет вручную отправить редакции ссылку на таблицу. Адреса задаются
через «Кому писать (владельцу)» и остаются в свойствах Apps Script.
Основные уведомления о новых документах отправляют задачи через Google
Drive.

## Задержка

Меню записывает запрос сразу, но не запускает Codex по событию. Его
обрабатывает ближайший плановый проход B. Для действительно срочной
правки владелец может вручную запустить B из раздела Scheduled.

## Если меняется раскладка таблицы

Apps Script не может импортировать `scripts/lib/sheet-columns.mjs`,
поэтому три индекса продублированы в начале `kontur-menu.gs`:
`COL_TOPIC`, `COL_STATUS`, `COL_NOTE`. При перестановке этих колонок
обновите индексы и переустановите скрипт в таблице.
