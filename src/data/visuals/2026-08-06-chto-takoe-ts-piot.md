# Визуал и промо — 2026-08-06-chto-takoe-ts-piot

## ТЗ на hero-изображение

- **Сюжет:** кассир на кассе в момент сканирования товара со штрих-кодом/кодом Data Matrix, на экране кассы — индикатор проверки (например, иконка загрузки или зелёная галочка).
- **Ключевой объект в кадре:** сканер штрих-кодов и упаковка товара с хорошо читаемым (но не текстовым) кодом маркировки.
- **Настроение и тон:** спокойная рабочая обстановка розничного магазина или кафе — не тревожная, не «штрафная». Модуль работает штатно, чек проходит.
- **Чего не должно быть:** людей крупным планом (только руки/силуэт за кассой), узнаваемых логотипов кассовых брендов, текста на изображении, реальных номеров НПА или сумм штрафов на картинке.
- **Формат:** горизонтальный (16:9), безопасная зона в верхней трети под наложение заголовка.

## Иллюстрации в тело статьи

1. **К разделу «Как работает ТС ПИоТ на кассе».** Тип: схема процесса (5 шагов из статьи — скан кода → запрос в ГИС МТ → ответ → пробитие чека/блокировка). Разгружает нумерованный список, который в тексте описан только словами.
2. **К разделу «Три даты ТС ПИоТ: 28.12.2025, 01.07.2026 и 01.10.2026».** Тип: таймлайн-инфографика с тремя точками на шкале времени и коротким подписанным смыслом каждой даты. В тексте уже есть таблица — иллюстрация нужна для быстрого визуального считывания хронологии, таблица остаётся для точных формулировок.
3. **К разделу «Штрафы за работу без ТС ПИоТ».** Тип: таблица-картинка с суммами по ст. 14.5 и 15.12 КоАП для ИП/юрлиц — версия таблицы из текста, адаптированная для соцсетей и превью (текстовая таблица markdown не всегда хорошо рендерится при шеринге).

Не предлагаю иллюстрацию к разделу «Пошаговое подключение» — там уже пронумерованный список из 5 шагов, картинка не разгрузит текст сильнее, чем нумерация.
